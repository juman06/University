This is a project that demonstrates the following:

*Abstract Class (Person): Base class for all people in the system.

*Inheritance (Student, Professor): Classes inheriting common fields (name, id) from Person.

*Interface (Payable): Used by Professor to calculate salaries.

*Generics (Storage<T>): A generic container class to store any data type.

*Encapsulation (Course): Class storing course details.
